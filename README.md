# Hi there 👋

I'm a learner of **Computer Science** working at the intersection of **machine learning, scientific computing, and research software engineering**.

My work focuses on applying machine learning to scientific problems, particularly **X-ray diagnostics for high-repetition-rate laser–plasma experiments**. Alongside the research itself, I'm interested in building **reproducible, maintainable, and well-engineered research software**.

I've contributed to and developed Python software for X-ray diagnostics, spanning detector simulation, spectral reconstruction, machine-learning workflows, and scientific evaluation.

I'm also actively developing my software engineering practice through smaller projects exploring **testing, CI, packaging, reproducible environments, automation, and developer tooling**.

## Research Software

### ⚛️ [MACR](https://github.com/brainthra/MACR)

**Contributor** — Material Attenuation Cross-Section Reference, a Python library for modelling material attenuation and detector response for X-ray diagnostics.

### 🔬 `lasim` *(releasing soon)*

**Author** — Python library for generating X-ray distributions and simulating measurements from Linear Absorption Spectrometers.

### 📈 `laspectron` *(releasing soon)*

**Author** — Python library for machine-learning-based reconstruction of incident X-ray spectra from Linear Absorption Spectrometer measurements.

These tools form part of my broader work on reproducible computational workflows for X-ray diagnostics.

## Research

### 🔬 [High-order X-ray Spectral Deconvolution](https://github.com/brainthra/las-highorder-deconvolution)

Machine-learning framework for reconstructing complex X-ray spectra from detector measurements.

The repository contains the software, configurations, trained models, benchmark results, and evaluation workflows required to reproduce the experiments associated with the research.

Accepted in **IOP Machine Learning: Science and Technology**.

### 🧠 [AI Brain Tumour Segmentation](https://github.com/brainthra/ai-brain-tumor-seg)

AI-based system for brain tumour segmentation and interactive 3D visualisation, combining a Python/Flask backend with a browser-based interface.

Published at **IEEE ISCAS 2025**.

## Software & Developer Projects

### 📝 [mdstats](https://github.com/brainthra/mdstats)

A lightweight Python command-line tool for analysing Markdown files, distributed through **PyPI**.

Built as a small software-engineering project using modern Python development practices including `uv`, `pytest`, `Ruff`, and `Pyright`.

### 📁 [dirsum](https://github.com/brainthra/dirsum)

A small Bash command-line utility for summarising directory contents.

Includes automated testing, ShellCheck static analysis, and **GitHub Actions CI**.

### 💻 [dotfiles](https://github.com/brainthra/dotfiles)

An ongoing project exploring reproducible development environments, configuration management, and developer tooling.

Modular Python implementation of Tic-Tac-Toe with random, rules-based, and minimax agents, supporting human play and automated bot tournaments.
